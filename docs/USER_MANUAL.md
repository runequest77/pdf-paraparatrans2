## 1. このソフトについて

PDF ParaParaTrans 2 は、英語の PDF や Web ページを、**段落ごとに読みやすく翻訳して整えていくためのアプリ**です。

ブラウザで使えるので、原文を見ながら訳文を少しずつ直していけます。

長い文書を「まとめて機械翻訳して終わり」ではなく、**「読みながら整える」** 使い方に向いています。

### こんな方に向いています

- ルールブックやマニュアルなど、長い PDF を少しずつ翻訳したい方
- 自動翻訳だけでは不安なので、原文を見ながら手直ししたい方
- 用語のゆれを減らしながら訳したい方
- PDF だけでなく、Web ページも同じ感覚で整理したい方

### このアプリの強み

- **段落単位で整えやすい** — PDF の段落がずれていても、順番や結合を直しながら読みやすくできます
- **列を見比べながら作業できる** — 原文、連結文、置換文、Auto、訳文、コメントを並べて確認できます
- **編集ボックスでその場で直せる** — 段落ごとに種別、結合、ステータス、訳文をまとめて調整できます
- **キーボードで高速に進められる** — 段落移動、タグ変更、結合、翻訳などをショートカットで操作できます
- **Ollama なら無料で始めやすい** — API 利用料なしで使え、文章を外部に送りたくない場合にも向いています

### まず知っておきたいこと

- アプリ本体はあなたの PC で動きます
- まず自動翻訳でたたき台を作り、そのあと必要な段落だけ直す使い方に向いています
- **無料で始めたいなら Ollama が便利**です。API 利用料がかからず、文章を外部に送らずに使えます
- Google 翻訳 API や DeepL API を使う場合は、翻訳する文章がそのサービスに送られます

## 2. できること

| できること | 説明 |
|---|---|

| 自動翻訳 | 段落ごとに自動翻訳し、必要な場所だけ手で直せます |

## 3. インストール

あなたの使い方に合わせて、次の方法から選んでください。

### 方法 A: Windows の exe 版を使う（いちばん手軽）

Python の準備は不要です。

1. Releases ページを開きます  
   https://github.com/runequest77/pdf-paraparatrans2/releases
2. 最新版の **Assets** から `pdf-paraparatrans.exe` をダウンロードします
3. 作業用フォルダを作り、その中に `pdf-paraparatrans.exe` を置きます
4. `pdf-paraparatrans.exe` をダブルクリックして起動します
5. ブラウザで `http://localhost:5077/` を開きます

### 方法 B: zip をダウンロードして使う

Windows / macOS / Linux で使えます。

1. Releases ページを開きます  
   https://github.com/runequest77/pdf-paraparatrans2/releases
2. **Source code (zip)** をダウンロードします
3. zip を展開します
4. Python をインストールします（まだ入っていない場合）
5. 展開したフォルダで**ターミナル**を開きます

> **ターミナルとは**  
> コマンドを入力してソフトを操作する画面です。Windows では「コマンドプロンプト」や「PowerShell」、macOS では「ターミナル」というアプリです。

6. 次のコマンドを入力して、必要なものを入れます

```bash
python -m pip install -r requirements.txt
```

7. 次のコマンドで起動します

```bash
python pdf-paraparatrans.py
```

8. ブラウザで `http://localhost:5077/` を開きます

> macOS や一部の環境では、`python` の代わりに `python3` を使います。

> 初回起動時に `.env` ファイルが自動で作られます。翻訳サービスの設定はこのファイルに書きます。詳しくは [8. 設定](#8-設定) をご覧ください。

### 方法 C: ブラウザだけで試す（GitHub Codespaces）

PC に入れたくない場合は、GitHub Codespaces を使う方法もあります。

> **GitHub Codespaces とは**  
> ブラウザ上でプログラムを動かせる仕組みです。自分の PC にアプリを入れなくても使えます。利用状況によって料金が発生する場合があります。

1. リポジトリ画面を開きます  
   https://github.com/runequest77/pdf-paraparatrans2
2. **Code** → **Codespaces** → **Create codespace** を選びます
3. 起動後にターミナルで次のコマンドを実行します

```bash
python -m pip install -r requirements.txt
python pdf-paraparatrans.py
```

4. 表示された 5077 番ポートをブラウザで開きます

> Codespaces を使う場合の注意点は [docs/CODESPACES.md](CODESPACES.md) もご覧ください。

### 翻訳サービスの準備

翻訳には、次のどれか 1 つを選びます。

| 翻訳サービス | 特徴 | 料金 | セットアップ |
|---|---|---|---|
| **Ollama** | 文章を外部に送らずに使える | **無料** | [SETUP_OLLAMA.md](../SETUP_OLLAMA.md) |
| Google 翻訳 API | 安定した翻訳品質 | 従量課金 | [SETUP_GOOGLE_TRANSLATE.md](../SETUP_GOOGLE_TRANSLATE.md) |
| DeepL API | 高い翻訳品質 | 従量課金/月額 | [SETUP_DEEPL.md](../SETUP_DEEPL.md) |

迷ったら、次の目安で選ぶと分かりやすいです。

- **まず無料で始めたい / 外部送信なしで使いたい → Ollama**
- 安定して使いたい → Google 翻訳 API
- DeepL を使い慣れている → DeepL API

## 4. 最初の使い方（クイックスタート）

最短で試す手順です。

1. アプリをインストールして起動します
2. ブラウザで `http://localhost:5077/` を開きます
3. 右上の **「PDFを追加」** を押して PDF を取り込みます
4. 一覧から PDF 名をクリックします
5. **「1.パラグラフ抽出」** を押します
6. **「4.全翻訳」** を押します
7. 訳文を見ながら、気になる段落だけ手で直します

これだけで、PDF 全体のたたき台訳ができあがります。

> すでに `data` フォルダに PDF を入れている場合は、手順 3 は不要です。そのまま一覧に表示されます。

## 5. 基本的な使い方

### 画面の流れ

このアプリには、大きく分けて 2 つの画面があります。

1. **一覧画面** — PDF やURLブックの一覧を管理する画面
2. **詳細画面** — 選んだ文書の段落を表示・編集する画面

基本的な作業の流れは次のとおりです。

1. 一覧画面で PDF を追加する
2. PDF 名をクリックして詳細画面を開く
3. **「1.パラグラフ抽出」** で段落を取り出す
4. 必要に応じて **「2.段落連結」** と **「3.全対訳置換」** を行う
5. **「4.全翻訳」** またはページ翻訳で訳を作る
6. 各段落を編集して、仕上がったものを「確定」にする

### 各列の見方

詳細画面では、段落ごとにいくつかの列が表示されます。それぞれの列の役割は次のとおりです。

| 列名 | 役割 | いつ見るか |
|---|---|---|
| **Html** | 元の PDF の文字情報 | 普段は非表示でも問題ありません |
| **原文** | PDF から取り出した元の文章 | 抽出結果の確認に使います |
| **連結文** | 切れていた段落をつないだ結果 | 段落の流れを整えたいときに見ます |
| **置換文** | 辞書を反映した翻訳前の文章 | 翻訳に送る前の最終形です |
| **Auto** | 自動翻訳の結果 | たたき台として確認します |
| **訳文** | 最終的に仕上げていく列 | 手直ししたい場合はここを編集します |
| **コメント** | 段落ごとのメモ欄 | 保留事項や注意点を書いておけます |

### おすすめの列表示

作業の段階に合わせて、表示する列を切り替えると見やすくなります。

- **構造調整中**: PDF / 原文 / 連結文
- **翻訳前の確認**: PDF / 置換文 / Auto
- **仕上げ中**: 連結文 / Auto / 訳文 / コメント

### よくある使い方

#### まず全体をざっと読みたいとき

1. PDF を追加します
2. **「1.パラグラフ抽出」** を押します
3. **「4.全翻訳」** を押します
4. 全体を読みながら、必要なところだけ直します

#### 用語をそろえながら丁寧に訳したいとき

1. 先に辞書へよく使う単語を入れます
2. **「3.全対訳置換」** を押します
3. **「4.全翻訳」** を押します
4. 固有名詞や専門用語がそろっているか確認しながら直します

#### 長い PDF を少しずつ進めたいとき

1. まず段落を抽出します
2. その日見るページだけ翻訳します
3. 直した段落を保存します
4. 次回は続きから進めます

## 7. 各機能の使い方

### 7.1 PDF の追加と管理

PDF をアプリに取り込んで、フォルダで整理する機能です。

#### こんなときに使います

- 新しい PDF を翻訳したいとき
- PDF をフォルダに分けて整理したいとき

#### PDF を追加する

1. 一覧画面を開きます
2. 右上の **「PDFを追加」** を押します
3. 翻訳したい PDF を選びます
4. 一覧に追加されたら、PDF 名をクリックして詳細画面を開きます

> PDF ファイルのサイズ上限は初期設定で 300MB です。変更する場合は [8. 設定](#8-設定) をご覧ください。

> `data` フォルダに直接 PDF ファイルを置いても、一覧に表示されます。

#### フォルダで整理する

1. 一覧画面でフォルダを作成します
2. PDF をフォルダに移動します
3. フォルダ名の変更や削除もできます

#### 入力するもの

- PDF ファイル（`.pdf` 形式）

#### 出力されるもの

- 一覧画面に PDF が追加されます
- 詳細画面で段落の作業を始められます

---

### 7.2 パラグラフ抽出

PDF から、翻訳の作業単位になる段落を取り出す機能です。

#### こんなときに使います

- 新しく PDF を追加したあと、最初に実行します
- PDF のテキスト情報を段落に分けて表示したいとき

#### 操作手順

1. 詳細画面を開きます
2. **「1.パラグラフ抽出」** を押します
3. 処理が終わると、画面に段落が並びます
4. 順番や区切りが大きくずれていないか確認します

#### 出力されるもの

- 段落ごとに分割された原文が画面に表示されます

#### 注意

- PDF の作り方によっては、段落の切れ方がきれいにならないことがあります
- その場合は [7.3 段落連結](#73-段落連結) や [7.7 編集ボックス](#77-編集ボックス) で調整できます

---

### 7.3 段落連結

途中で切れてしまった段落をつなぎ合わせる機能です。

#### こんなときに使います

- 抽出した段落が文の途中で切れているとき
- 段落の流れを整えたいとき

#### 操作手順

1. **原文** と **連結文** の列を表示します
2. 途中で切れている段落を確認します
3. 必要な段落で結合を切り替えます（編集ボックスの「結合」、またはキーボードショートカット `Alt + ;`）
4. **「2.段落連結」** を押します
5. **連結文** 列で結果を確認します

#### 入力するもの

- 段落ごとの結合設定（つなげるかどうか）

#### 出力されるもの

- **連結文** 列に、段落をつないだ結果が表示されます
- **置換文** 列も同時に更新されます

### 7.4 辞書管理

よく出る用語や固有名詞を辞書に登録して、翻訳時に統一する機能です。

#### こんなときに使います

- 固有名詞（人名、地名、専門用語など）の訳をそろえたいとき
- 自動翻訳では正しく訳されない用語があるとき

#### 辞書の種類

| 辞書の種類 | 説明 | 保存場所 |
|---|---|---|
| 共通辞書 | すべての文書で使われる辞書 | `dicts/default.txt` |
| 追加の共通辞書 | 分野別の共通辞書 | `dicts/` フォルダ内の任意の `.txt` ファイル |
| 文書別辞書 | 特定の文書だけで使われる辞書 | 各文書ごとの `*.dict.txt` |

#### 辞書に登録する

**方法 1: 詳細画面から登録する**

1. 詳細画面で登録したい単語を選択します
2. **「辞書登録」** を押します
3. 英語と日本語の対訳を入力します
4. 保存します

**方法 2: 辞書メンテナンス画面から登録する**

1. 一覧画面または詳細画面から **辞書メンテナンス** 画面を開きます
2. 辞書の一覧が表示されます
3. 新しい用語を追加したり、既存の用語を編集したりできます

**方法 3: テキストファイルを直接編集する**

辞書ファイルはタブ区切りのテキストファイルです。メモ帳などで直接編集できます。

```
英語	日本語	状態	出現回数
Bladesharp	《鋭刃》	0	3
```

> **タブ区切りとは**  
> 項目と項目の間をキーボードの Tab キーで区切る書き方です。スペースではなく Tab を使います。

#### 辞書の状態

| 状態 | 意味 |
|---|---|
| `0` | 大文字小文字を区別せず置換します |
| `1` | 大文字小文字が一致する場合のみ置換します |
| `2` 以上 | 自動生成用の予約状態です（通常の置換では使われません） |

#### 辞書メンテナンス画面でできること

- 辞書の一覧表示と一括更新
- 同じ単語の訳を比較する
- 辞書エントリの自動翻訳
- 辞書間での用語の転送

> 詳しくは [辞書編集ガイド](DICTIONARY_EDITING.md) をご覧ください。

### 7.5 対訳置換

辞書に登録した用語を、文書全体の文章に反映する機能です。

#### こんなときに使います

- 辞書を登録したあと、翻訳前に用語を統一したいとき
- 翻訳エンジンに送る文章の用語をそろえたいとき

#### 操作手順

**文書全体に反映する場合**

1. 辞書を登録・編集します
2. **「3.全対訳置換」** を押します
3. **置換文** 列で結果を確認します

**1 ページだけ反映する場合**

1. 対象のページを表示します
2. **「ページ対訳置換」** を押します
3. **置換文** 列で結果を確認します

#### 入力するもの

- 辞書（事前に登録しておく必要があります）

#### 出力されるもの

- **置換文** 列に、辞書の用語が反映された文章が表示されます

> 辞書を編集しただけでは反映されません。必ず「全対訳置換」または「ページ対訳置換」を実行してください。

### 7.6 翻訳

段落を自動翻訳する機能です。Google 翻訳、DeepL、または Ollama を使って翻訳します。

#### こんなときに使います

- 文書全体のたたき台訳を作りたいとき
- 1 ページずつ確認しながら進めたいとき
- 特定の段落だけ試しに翻訳したいとき

#### 操作手順

**文書全体を翻訳する**

1. **「4.全翻訳」** を押します
2. 未翻訳の段落がまとめて翻訳されます
3. **Auto** 列に翻訳結果が表示されます

**1 ページだけ翻訳する**

1. 翻訳したいページを表示します
2. **「ページ翻訳」** を押します（またはキーボードショートカット `Ctrl + Alt + /`）

**1 段落だけ翻訳する**

1. 翻訳したい段落を選択します
2. 編集ボックスの **「自動翻訳」** を押します（またはキーボードショートカット `Alt + /`）

#### 入力するもの

- **置換文** 列の内容が翻訳エンジンに送られます

#### 出力されるもの

- **Auto** 列に自動翻訳の結果が表示されます
- ステータスが「自動翻訳」に変わります

#### 翻訳エンジンの切り替え

使用する翻訳エンジンは、詳細画面の上部にある翻訳エンジン選択メニューで確認・変更できます。

> 翻訳エンジンの設定方法は [8. 設定](#8-設定) をご覧ください。

### 7.7 編集ボックス

段落を個別に編集するための機能です。

#### こんなときに使います

- 段落の訳文を手で直したいとき
- 段落の種別（見出し、本文など）を変えたいとき
- 段落の結合や分割を調整したいとき

#### 操作手順

1. 各段落の **`...`** ボタンを押します（または `F2` キー）
2. 編集ボックスが開きます
3. 必要に応じて次を調整します
   - **結合**: 前の段落とつなげるかを切り替えます
   - **種別**: 本文、見出し、ヘッダ、フッタなどを選びます
   - **同スタイルを一括更新**: 似た見た目の段落をまとめて整えます
   - **自動翻訳**: その段落だけ翻訳します
   - **ステータス**: 未翻訳 / 自動翻訳 / 下訳 / 確定
4. 訳文を整えたら **保存** を押します（または `Ctrl + S`）

#### ステータスの使い分け

| ステータス | 意味 | こんなときに使います |
|---|---|---|
| **未翻訳** | まだ手を付けていない段落 | 最初の状態です |
| **自動翻訳** | 自動翻訳をかけた段落 | 機械翻訳直後の状態です |
| **下訳** | 見直し途中の段落 | 手直し中の段落に設定します |
| **確定** | 仕上がった段落 | 完成した段落に設定します |

迷ったら、直し途中のものは「下訳」、完成したものは「確定」にしておくと管理しやすいです。

#### 段落の種別

段落には種別を設定できます。見出しを設定すると、目次パネルに反映されます。

| 種別 | 説明 |
|---|---|
| 本文 | 通常の本文 |
| 見出し（h1〜h6） | 章や節の見出し |
| header | ページのヘッダ部分 |
| footer | ページのフッタ部分 |

> キーボードショートカット `Alt + 0〜9` でも種別を変更できます。

### 7.8 キーボードショートカット

キーボードだけで高速に編集するための機能です。

#### こんなときに使います

- マウスを使わずに素早く作業を進めたいとき
- 大量の段落を効率よく編集したいとき

#### まず覚えたいショートカット

| キー | 動作 |
|---|---|
| `↑` / `↓` | 段落を移動します |
| `Shift + ↑` / `Shift + ↓` | 選択しながら移動します |
| `Alt + ↑` / `Alt + ↓` | 選択中の段落を上下に並べ替えます |
| `Alt + 0〜9` | 段落の種別を変更します |
| `Alt + +` または `Alt + ;` | 結合の切り替えをします |
| `Alt + /` | 今の段落だけ翻訳します |
| `Ctrl + Alt + /` | 今のページを翻訳します |
| `F2` | 編集ボックスの表示を切り替えます |
| `Ctrl + S` | 保存します |
| `Ctrl + Shift + K` | KeyHUD の表示を切り替えます |

#### ショートカット一覧の確認方法

- 画面右上の **「HotKey」** ボタンを押すと、ショートカット一覧を表示できます

#### KeyHUD

> **KeyHUD とは**  
> 押したキーとその意味を画面上にリアルタイム表示する機能です。ショートカットを覚えるときに便利です。

- `Ctrl + Shift + K` で表示を切り替えます
- 表示中は、押したキーと説明がその場で確認できます

ショートカットを少しずつ覚えると、マウス中心よりかなり速く作業できます。

### 7.12 URL ブック（Web ページの翻訳）

PDF だけでなく、Web ページを翻訳対象にする機能です。

#### こんなときに使います

- Web サイトや記事を翻訳したいとき
- Web ページを PDF と同じ流れで整理したいとき

#### 最短手順

1. 一覧画面で **「URLを追加」** を押します
2. 取り込みたいページの URL を入力します
3. 詳細画面が開きます
4. URL プレビューで対象ページを表示します
5. **「取込」** で現在ページを取り込みます
6. 取り込んだページは PDF と同じように翻訳・整理できます

#### 取り込み方法

| 方法 | 説明 |
|---|---|
| 1 ページ追加 | URL を指定してページを追加します |
| URL 取込 | URL を指定して本文を取得し取り込みます |
| HTML 直接取込 | 取得済みの HTML を直接取り込みます |
| クロール | 開始 URL から同じサイト内のリンクをたどって追加します |

> **クロールとは**  
> Web サイト内のリンクを自動的にたどって、複数のページをまとめて取り込む機能です。

#### サイトルール（取り込み範囲の調整）

Web ページによっては、メニューや広告など不要な部分も取り込まれることがあります。サイトルールを使うと、取り込む範囲を調整できます。

1. 詳細画面の **「ルール」** を押します
2. 取り込む範囲を設定します
   - **対象範囲（include）**: 取り込みたい部分を指定します
   - **追加要素（add）**: 追加で取り込みたい部分を指定します
   - **除外要素（exclude）**: 取り込みたくない部分を指定します
3. 設定を保存します

> 詳しくは [URLブックガイド](URL_BOOK_GUIDE.md) をご覧ください。

#### 出力されるもの

### 7.15 ブラウザ拡張

Chrome や Edge から直接 Web ページを取り込むための拡張機能です。

## 8. 設定

### 設定ファイル（.env）

> **.env ファイルとは**  
> アプリの動作を変更するための設定ファイルです。テキストファイルなので、メモ帳やテキストエディタで開いて編集できます。初回起動時に自動で作られます。

設定を変更したあとは、アプリを再起動してください。

### 翻訳エンジンの設定

使用する翻訳エンジンを選びます。

```
TRANSLATOR
```

使用する翻訳エンジンを指定します。

入力できる値: `google` / `deepl` / `ollama` / `google_v3`

初期値: `google`

#### Google 翻訳 API を使う場合

```
TRANSLATOR=google
GOOGLE_API_KEY=（取得した API キー）
```

API キーの取得方法は [SETUP_GOOGLE_TRANSLATE.md](../SETUP_GOOGLE_TRANSLATE.md) をご覧ください。

#### DeepL API を使う場合

```
TRANSLATOR=deepl
DEEPL_AUTH_KEY=（取得した認証キー）
```

認証キーの取得方法は [SETUP_DEEPL.md](../SETUP_DEEPL.md) をご覧ください。

#### Ollama を使う場合

```
TRANSLATOR=ollama
```

API キーは不要です。Ollama のインストールが必要です。

詳しくは [SETUP_OLLAMA.md](../SETUP_OLLAMA.md) をご覧ください。

追加の設定:

```
OLLAMA_MODEL
```

使用する AI モデルを指定します。

初期値: `gemma3:12b`

```
OLLAMA_BASE_URL
```

Ollama が動いているアドレスを指定します。

初期値: `http://localhost:11434`

### サーバーの設定

```
PORT
```

アプリが使うポート番号を指定します。他のアプリとぶつかる場合に変更します。

初期値: `5077`

> **ポート番号とは**  
> アプリがデータをやり取りするための番号です。別のアプリが同じ番号を使っていると起動できないことがあります。

```
LOG_DIR
```

ログファイルの保存先を指定します。

初期値: `logs`

```
LOG_LEVEL
```

ログの詳しさを指定します。

入力できる値: `DEBUG` / `INFO` / `WARNING` / `ERROR`

初期値: `WARNING`

### ファイルアップロードの設定

```
MAX_PDF_UPLOAD_MB
```

アップロードできる PDF ファイルの最大サイズ（MB 単位）を指定します。

初期値: `300`

```
CHUNK_UPLOAD_THRESHOLD_MB
```

大きなファイルを分割してアップロードする境界サイズ（MB 単位）を指定します。

初期値: `15`

### AI 連携の設定

AI を使った表の再抽出（[7.14](#714-ai-を使った表の再抽出)）を使う場合に設定します。

```
AI_PROVIDER
```

使用する AI プロバイダを指定します。

入力できる値: `ollama` / `gemini`

初期値: `ollama`

```
GEMINI_API_KEY
```

Gemini を使う場合の API キーを指定します。

初期値: （なし）

> Gemini の API キーは https://aistudio.google.com/ から無料で取得できます。

```
GEMINI_MODEL
```

Gemini で使用するモデルを指定します。

初期値: `gemini-2.5-flash`

## 9. よくある質問

### Q. 無料で使えますか？

アプリ本体は無料です。

ただし、Google 翻訳 API や DeepL API は利用量によって料金がかかることがあります。**Ollama は API 利用料なしで使えるので、無料で始めたい方に向いています。**

### Q. 文章は外部に送られますか？

Google 翻訳 API や DeepL API を使う場合は、翻訳する文章がそのサービスに送られます。

Ollama を使う場合は、基本的にあなたの PC の中だけで処理できます。

### Q. PDF ファイルそのものが送られますか？

通常は、翻訳の対象になる文章だけが送られます。PDF ファイルそのものをそのまま外部へ送る使い方ではありません。

### Q. どの翻訳サービスを選べばいいですか？

迷ったら Google 翻訳 API が始めやすいです。

**とにかく無料で試したい、外部に送りたくない、という場合は Ollama を選んでください。**

### Q. `.env` って何ですか？

翻訳サービスの設定を書くためのファイルです。

初回起動時に自動で作られます。中身はテキストなので、メモ帳などで開いて設定できます。

詳しくは [8. 設定](#8-設定) をご覧ください。

### Q. 段落の区切りを変えたいです。

編集ボックスの **「結合」** で、前の段落とつなげるかを切り替えられます。

キーボードショートカット `Alt + ;` でも切り替えできます。

変更後は **「2.段落連結」** を実行してください。

### Q. 翻訳済みの段落を再翻訳したいです。

翻訳済みの段落でも、編集ボックスの **「自動翻訳」** や `Alt + /` で再翻訳できます。

### Q. 辞書を変えたのに反映されません。

辞書を編集しただけでは反映されません。**「3.全対訳置換」** または **「ページ対訳置換」** を実行してください。

### Q. 作業データはどこに保存されますか？

アプリのフォルダ内の `data/` フォルダに保存されます。バックアップを取りたい場合は、このフォルダをコピーしてください。

## 10. トラブルシューティング

### 画面が開かない

1. ブラウザで `http://localhost:5077/` を直接開いてみてください
2. 別のアプリが 5077 番ポートを使っていないか確認してください
3. それでも開けない場合は、`.env` の `PORT` を別の番号（例: `5078`）に変えて再起動してください

### 翻訳が動かない

1. `.env` の `TRANSLATOR` の設定を確認してください
2. 使用する翻訳サービスの API キーが正しく設定されているか確認してください
3. Ollama を使う場合は、Ollama が起動しているか確認してください（`ollama list` コマンドで確認できます）

### 翻訳が遅い

- Ollama を使っていて翻訳が遅い場合は、より軽量なモデル（`gemma3:4b` など）に変更してみてください
- `.env` の `OLLAMA_MODEL` を変更してアプリを再起動します

### PDF の段落が崩れている

- PDF の作り方によっては、段落の切れ方がきれいにならないことがあります
- **「2.段落連結」** を使って段落をつなぎ直してください
- 必要な段落だけ編集ボックスで手動調整することもできます

### 文字化けしている

- シンボルフォントが原因の場合は、[7.13 シンボルフォント](#713-シンボルフォント) の機能で対応できます
- **「シンボルフォント」** から置換ルールを登録し、**「シンボル置換」** を実行してください

### 大きな PDF がアップロードできない

- 初期設定では 300MB までアップロードできます
- それ以上の場合は `.env` の `MAX_PDF_UPLOAD_MB` を変更してください

### 「Ollama サーバーに接続できません」と表示される

1. Ollama が起動しているか確認してください（`ollama list` コマンド）
2. Windows の場合、タスクトレイに Ollama のアイコンがあるか確認してください
3. `.env` の `OLLAMA_BASE_URL` が正しいか確認してください（初期値: `http://localhost:11434`）

### ブラウザ拡張が動かない

1. 拡張機能が有効になっているか確認してください
2. アプリが起動しているか確認してください
3. 拡張のポップアップで ParaParaTrans の URL が正しく設定されているか確認してください

## 12. 用語集

このマニュアルで使われている用語の説明です。

| 用語 | 説明 |
|---|---|
| **API** | アプリケーション同士がデータをやり取りするための仕組みです |
| **API キー** | 翻訳サービスなどを利用するための認証コード（パスワードのようなもの）です |
| **Codespaces** | GitHub が提供する、ブラウザ上でプログラムを動かせる仕組みです |
| **HTML** | Web ページを表示するためのファイル形式です |
| **JSON** | データを保存するためのテキスト形式です |
| **KeyHUD** | 押したキーとその意味を画面上にリアルタイム表示する機能です |
| **Markdown** | 見出しや箇条書きなどを簡単な記号で表現するテキスト形式です |
| **Ollama** | PC の中で AI を動かすためのソフトです。無料で使えます |
| **PDF** | Adobe が開発した文書ファイル形式です。レイアウトを保ったまま表示できます |
| **ターミナル** | コマンドを入力してソフトを操作する画面です |
| **ポート番号** | アプリがデータをやり取りするための番号です |
| **クロール** | Web サイト内のリンクを自動的にたどって、複数のページを取り込む機能です |
| **シンボルフォント** | 特殊な記号やアイコンを表示するためのフォントです |
| **タブ区切り** | 項目と項目の間を Tab キーで区切るデータ形式です |
| **AI プロバイダ** | AI の処理を提供するサービスやソフトのことです |
| **ステータス** | 段落の作業状況を表す値です（未翻訳/自動翻訳/下訳/確定） |
